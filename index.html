Sources & assumptions
  • Coding agent seat, $100/user/mo: Team Premium annual pricing for Claude Code, public trackers, Apr 2026. Public range $100–150; default uses the low end. Enter your own per-user cost for Claude Code, Codex, or another coding harness.
  • Reference $20/fix: each remediation ships as a PR — anchored on Anthropic's published Code Review band of $15–25/PR for Claude Opus 4.8 (Jun 2026), midpoint. Claude Opus 5 is list-priced identically ($5 / $25 per MTok), so the default model runs at 1.00×.
  • Model multipliers: each model's output-token list price relative to the Claude Opus 4.8 reference ($25 / MTok). Full table below.
  • 8 fixes/dev/month: industry research puts the average at ~2 PRs per developer per week.
  • Token reduction, up to 91.7%: Endor Labs benchmark (442 AppSec prompts, 12 OSS projects, 6 languages) comparing agents with deterministic security context vs. rediscovering context themselves. Default 80% is conservative; the slider allows up to 99% for what-if scenarios.
  • Scope: seat licenses + per-fix token spend only. Excludes engineering time, CI minutes, orchestration infra. Public pricing — not an Anthropic quote.
