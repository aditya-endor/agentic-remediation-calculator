Under the hood

How it's calculated
A

Seat floor — the fixed cost of agent seats

developers × seat license × 12
150 × $100 × 12 = $180,000 / year. This is fixed — it's the same with or without Endor Labs.

B

Token bill — what the fixes themselves cost at list price

developers × fixes/dev/month × 12 × $/fix
150 × 8 × 12 = 14,400 fixes × $20 = $288,000 / year. The $/fix is the reference price × the model's multiplier.

C

Apply the context lever — same fixes, fewer tokens

token bill × (1 − reduction) + seat floor
$288,000 × (1 − 80%) = $57,600 + $180,000 = $237,600 total, saving $230,400. Savings = total without − total with.

Sources & assumptions
  • Seat license, $100/seat/month: Team Premium annual pricing from public price trackers, April 2026. Public range is $100–150; the default uses the low end.
  • Reference $20/fix: each agentic remediation ships as a PR, so we anchor on Anthropic's published Code Review band of $15–25 per PR for Claude Opus 4.8, June 2026. The default is the midpoint.
  • Model multipliers: GPT-5.5 ≈ 1.2× and Claude Fable 5 ≈ 2.0× the Opus 4.8 reference, derived from the same public pricing bands.
  • 8 fixes per developer per month: industry research puts the average at roughly 2 PRs per developer per week.
  • Token reduction, up to 91.7%: Endor Labs benchmark comparing remediations where the agent receives deterministic security context (dependency graph, reachability, exploitability) against remediations where it rediscovers that context itself. The default is set at a conservative 80%.
  • Scope: the estimate covers seat licenses and per-fix token spend only. It excludes engineering time, CI minutes, and orchestration infrastructure. Based on public pricing — not an Anthropic quote.
